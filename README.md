# ATATV44 Web Sitesi

Retro TV temalı kara mizah topluluğu web sitesi.

## Özellikler

- Retro TV arayüzü
- Nostaljik ses efektleri
- Responsive tasarım
- Discord entegrasyonu

## Kurulum

1. Repository'yi klonlayın:
```bash
git clone https://github.com/KULLANICI_ADI/atatv44.com.git
```

2. Proje dizinine gidin:
```bash
cd atatv44.com
```

3. `index.html` dosyasını bir web tarayıcısında açın.

## Geliştirme

Projeyi geliştirmek için:

1. Bu repository'yi fork'layın
2. Feature branch'i oluşturun (`git checkout -b feature/YeniOzellik`)
3. Değişikliklerinizi commit'leyin (`git commit -m 'Yeni özellik: Açıklama'`)
4. Branch'inizi push'layın (`git push origin feature/YeniOzellik`)
5. Pull Request oluşturun
